## Client

- Pointed default server address at the production game server (`185.213.26.59`). The `--address`/`-ip` CLI override still works for local development.

## Usage

Run with:

```bash
java -jar void-client-0.1.1.jar
```

Override host/port for local dev:

```bash
java -jar void-client-0.1.1.jar --address xxx.xxx.xxx.xxx --port xxxxx
```
