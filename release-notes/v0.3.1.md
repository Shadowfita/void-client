# Void Client v0.3.1

Corrective visual and compatibility release.

- Restores the intended fractional pixel supersampling path for RuneScape UI sprites and font atlases.
- Uses exact whole-number nearest-neighbour expansion before fractional minification.
- Replaces the camera-independent RuneLite world projection approximation with the native revision-634 renderer projection.
- Uses the actual current plane, scene base and bridge-aware native terrain heights.
- Corrects NPC overhead-height anchoring.
- Changes first-run plugin defaults to a conservative new-player profile: neutral interface/animation/XP QoL enabled; gameplay-altering and world-overlay helpers opt-in.
