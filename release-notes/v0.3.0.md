# Void Client v0.3.0

This release promotes the 0.3.0 stabilization work into the main client line.

Highlights:

- Preserves the corrected native-resolution RuneScape interface scaling and decimal scale support.
- Keeps the Linux JAGGL/OpenGL resize path on the client/render thread to prevent sidebar/resize native crashes.
- Reworks the native 634 interface render pipeline so interaction-driven HUD layout changes are re-established correctly.
- Adds real JAGGL composition points for RuneLite overlay layers, allowing scene and widget overlays to participate in the hardware-rendered frame.
- Removes the unsupported FlatLaf style that generated repeated sidebar UI errors.
- Retains the RuneLite-style QoL plugin set, modern desktop shell and ProGuard mouse-wheel zoom fix.
- Updates the client/build version to 0.3.0.

The attached JAR is the ProGuard release build and includes a SHA-256 checksum.
