# Void Client v0.2.0

This release rolls the Shadowfita fork's RuneLite integration work into a reproducible GitHub release build.

Highlights:

- Native-resolution RuneScape interface scaling while keeping the 3D scene at native resolution.
- Decimal interface scaling and corrected resize/layout state.
- Mouse-wheel camera zoom retained correctly through ProGuard release builds.
- Modern FlatLaf RuneLite-style desktop shell.
- RuneLite-style quality-of-life plugins including menu swapping, ground items, indicators, idle notifications, inventory/bank tags, opponent information, chat improvements, loot tracking and 2011 clue support.
- Linux window-shell cleanup so the client uses a single title/window bar with the RuneLite navigation controls in the persistent side toolbar.

The attached JAR is the ProGuard release build and includes a SHA-256 checksum.
